# Hacker_Bot

A fun live Slack hacker bot with many features useful to hackers.



## What is this about?

This is a slack bot built for the hack club slack workspace that let's you run lots of fun tools, api utilities, and simple automation commands directly inside slack. I made this because I love hacking because when we try hard to hack something(ethically), the dopamine hit it gives is indescribable

## How does it work?

the bot is already installed in the hack club slack workspace.
to use it:
go to slack and run commands starting with / . That's all

setup (optional):

if you want to run your own version:


clone the repository:

git clone (https://github.com/akshaykpillai369-max/hackerbot)

cd https://github.com/akshaykpillai369-max/hackerbot/

npm install

set environment variables (create a .env file):

SLACK_BOT_TOKEN=your_token

SLACK_APP_TOKEN=your_token

run the bot:

node index.js

## Commands available in hackerbot now:

- /hackerbot-ping - Check the bot is live
- /hackerbot-vuln - Get vulnerabilities
- /hackerbot-passcheck - Test password strength.
- /hackerbot-catfact - Get a random cat fact.
- /hackerbot-joke- Get a joke.
- /hackerbot-help - View available commands
